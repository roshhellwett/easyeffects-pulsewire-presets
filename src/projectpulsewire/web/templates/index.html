IRS (Impulse Response) Usage Guide

Impulse Response files capture acoustic physical characteristics of hardware audio processors, concert spaces, and headphone frequency responses.

EasyEffects Setup Steps:

  1. Install your desired IRS file using this studio or CLI.
  2. Open EasyEffects → select Output Effects.
  3. Click Add Effect → select Convolver.
  4. In Convolver settings, click the Import / File icon.
  5. Select your installed .irs file from the IRS folder.
  6. Note: Always place a Limiter plugin after the Convolver to prevent digital clipping.
